# VKCoder Chrome Extension

## Setup
1. Run `vkcoder --serve` on your Mac
2. Open Chrome -> chrome://extensions
3. Enable "Developer mode" (top right)
4. Click "Load unpacked" -> select this folder
5. Right-click any webpage -> "Analyze with VKCoder"

## Generate Icons
Create 48x48 and 128x128 PNG icons named icon48.png and icon128.png in this folder.
You can use any icon generator or create simple ones.
